Sports Ease Management System 🏅
A beginner-friendly sports facility management system built to implement object-oriented programming (OOP) concepts using Java.

Project Overview
The Sports Ease Management System allows users to:

Book Facilities – Reserve courts for sports like badminton and football.
Hire Coaches – Schedule sessions with available sports coaches.
Rent Equipment – Borrow sports equipment such as rackets and balls.

Key Concepts Implemented:

Classes and Objects
Inheritance
Polymorphism
Encapsulation
Abstraction

Technologies Used:
Programming Language – Java (No external frameworks or databases used)
Notes
This project was created for educational purposes and to strengthen OOP concepts.
Future updates may include more features or a graphical user interface (GUI).
